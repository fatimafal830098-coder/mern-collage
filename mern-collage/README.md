## ✨ Overview

**Mern Collage** is a full-stack image gallery application built with the MERN stack.

It allows users to upload images, add metadata, search and sort their collection, edit image information, mark images as favorites, view images, and delete unwanted files.

The project combines a modern React frontend with a Node.js and Express backend, MongoDB for metadata persistence, and local storage for uploaded image files.

## 🚀 Key Features

| Feature | Description |
|---|---|
| 📤 Image Upload | Upload images with metadata |
| 📝 Metadata | Add title, description and tags |
| ✏️ Edit | Update metadata without re-uploading |
| ❤️ Favorites | Mark images as favorites |
| 🔍 Search | Search images using metadata |
| ↕️ Sorting | Sort images by recent/oldest |
| 🖼️ Viewer | View images clearly |
| 🗑️ Delete | Remove unwanted images |
| ⏳ Loading | Shows loading feedback |
| ⚠️ Error Handling | Handles failed requests |
| 📭 Empty States | Handles empty gallery/results |
